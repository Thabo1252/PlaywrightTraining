Junior QA Portfolio – Manual and Automation Testing

Project Overview

This project demonstrates my practical skills in software testing using manual testing and test automation.

I am using the SauceDemo website as a practice application to test login functionality and understand how software testers identify, execute, document and automate test scenarios.

Tools and Technologies

JavaScript

Playwright

Node.js

Visual Studio Code

Git and GitHub

Google Sheets / Excel

Manual Testing

I created and executed manual test cases covering:

Successful login with valid credentials

Login with an incorrect password

Login attempt using a locked-out user

Login attempt with a blank password

Login attempt with a blank username

Test results are documented in QA_Test_Cases.xlsx.

Automation Testing

I developed Playwright automated tests covering:

Successful user login

Unsuccessful login using an incorrect password

How to Run the Tests

Clone this repository.

Open the project folder in VS Code.

Install dependencies:

npm install

Run the Playwright tests:

npx playwright test

Project Objective

My objective is to demonstrate my understanding of manual testing, test case development, test execution, defect identification and basic test automation.
